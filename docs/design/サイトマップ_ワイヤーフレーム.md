## 1. サイトマップ（全体構造）

```
TOP（トップページ）
│
├── お店紹介 / こだわり        /about
│     ├─ 店主の想い・歴史
│     └─ 鮮度・仕入れ・品質へのこだわり
│
├── 商品紹介                   /products
│     ├─ 和牛
│     ├─ 黒豚
│     └─ 惣菜・加工品（店頭中心の案内）
│
├── 通販（オンラインストア）    /shop  → ASP(BASE/STORES) or Shopify
│     ├─ ギフト 松竹梅
│     ├─ 看板（A5ステーキ/特選和牛たたき）
│     ├─ 和牛
│     ├─ 黒豚
│     └─ 冷凍惣菜（許可が整い次第）
│
├── 店舗案内                   /stores
│     ├─ 雑餉隈本店
│     └─ 月隈店
│
├── お客様の声 / 実食レビュー    /reviews
│
├── メディア・取材実績          /media
│
├── お知らせ / ブログ          /news
│
├── よくある質問（FAQ）        /faq
│
└── お問い合わせ              /contact
      ├─ 一般問い合わせフォーム
      └─ 業務用・卸の相談

［全ページ共通］ ヘッダー / フッター / 追従CTA(モバイル) / SNS導線 / LINE導線
```

### ページ優先度（公開時）
| 優先 | ページ | 理由 |
|------|--------|------|
| ★★★ | TOP / 店舗案内 / 商品紹介 / お問い合わせ | 最低限の「お店の信頼」確保 |
| ★★★ | 通販 | 主目的の一つ |
| ★★☆ | お客様の声 / お店紹介 / メディア | 信頼・購入後押し |
| ★☆☆ | お知らせ / FAQ | 運用で育てる |

### 4.2 商品紹介 /products
```
タブ/アンカー: [和牛][黒豚][惣菜・加工品]
各カテゴリ: 写真カード（商品名・特徴・価格目安）
※価格改定運用を考慮し「目安」表記＋通販リンク
末尾CTA: [🛒 通販で購入する]
```

### 4.3 通販 /shop（ASP/Shopify連携）
```
┌──────────────────────────┐
│ カテゴリ: ギフト/看板/和牛/  │
│ 黒豚/冷凍惣菜               │
├──────────────────────────┤
│ 商品グリッド（写真/名/価格） │
│ 各商品 → カート → 決済      │
│ ・送料: ○円以上無料表示     │
│ ・クール冷凍便/日時指定      │
│ ・のし/ラッピング選択        │
├──────────────────────────┤
│ 特商法表記 / 配送・返品案内  │
└──────────────────────────┘
```

### 4.4 お客様の声 /reviews
```
フィルタ: [すべて][和牛][黒豚][ギフト]
レビューカード: ★評価 / コメント / 写真 / 商品名リンク
（初期は管理者がオーナー確認後に掲載）
```

### 4.5 お問い合わせ /contact
```
種別選択: [一般] [業務用・卸]
入力: 氏名 / 連絡先 / 内容 / 同意チェック
送信 → 自動返信メール（reCAPTCHA）
補助導線: 電話 / LINE
```
