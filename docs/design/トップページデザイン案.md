## 1. デザインコンセプト

> **「お肉のプロの目利き × 福岡・地元の安心感」**

清潔で信頼できる精肉店の佇まいに、テレビ取材実績のある“本物”の説得力と、
ご近所さんにも愛される温かみを両立させる。**写真（シズル感）が主役**。

3つのキーワード：
- **新鮮さ** … 赤身のみずみずしさ、サシの美しさを写真で見せる
- **信頼** … 清潔な白基調、整然としたレイアウト、取材実績
- **親しみ** … 店主の顔、手書き風のひと言、地域の言葉

## 2. カラーパレット

| 役割 | 色 | HEX(案) | 使いどころ |
|------|----|---------|-----------|
| ベース | オフホワイト | `#FAF8F5` | 背景。清潔感 |
| メイン | 和牛レッド（深紅） | `#9B2D30` | ロゴ・見出し・帯。肉の赤 |
| アクセント | ボルドー | `#6E1E1E` | ボタンhover、強調 |
| ゴールド | くすみ金 | `#C9A24B` | ギフト・高級感の差し色 |
| 墨黒 | チャコール | `#2B2B2B` | 本文テキスト、締め |
| サブ | ウォームグレー | `#8C857C` | 補助テキスト・罫線 |

```
■ベース #FAF8F5   ■和牛レッド #9B2D30   ■ボルドー #6E1E1E
■ゴールド #C9A24B  ■墨黒 #2B2B2B        ■グレー #8C857C
```

> 白を広く取り、要所に**和牛レッド**、ギフトまわりに**ゴールド**。
> 赤を使いすぎず「清潔＞こってり」のバランスにする。

## 3. タイポグラフィ

| 用途 | フォント(案) | 意図 |
|------|-------------|------|
| 大見出し（屋号・キャッチ） | 明朝系（Noto Serif JP / 游明朝） | 高級感・上質さ |
| 見出し・本文 | ゴシック系（Noto Sans JP） | 可読性・親しみ |
| 数字・英字（価格・店舗） | 細身サンセリフ | すっきり読みやすく |
| アクセント（ひと言） | 手書き風（任意・控えめ） | 地域の温かみ |

- 本文サイズ：16px〜（モバイル可読性）
- 行間：1.7〜1.8でゆったり

## 4. トップページ ビジュアル構成（セクション別トーン）

### ① ヒーロー（第一印象）
```
┌──────────────────────────────────────────┐
│   [全幅：A5ステーキ or 特選和牛たたきの     │
│    シズル写真。湯気・断面・サシ]            │
│                                            │
│   ┌──────────────────────┐                │
│   │ 福岡・雑餉隈の精肉店    │                │
│   │ お肉のプロが選ぶ        │ ← 明朝・白文字 │
│   │ こだわりの一頭          │                │
│   │ [🛒 通販を見る] [🏠 店舗] │                │
│   └──────────────────────┘                │
└──────────────────────────────────────────┘
```
- 大判写真にダークオーバーレイ→白文字で可読性確保
- CTAは2つ：**主＝通販（和牛レッド）／副＝店舗（白枠）**

### ② お知らせ（細い帯）
- 白背景に1行ずつ。日付＋タイトル。控えめに。

### ③ こだわり（抜粋）
- 左：店主/店内の写真／右：短い宣言文（明朝見出し＋ゴシック本文）
- 3アイコン：**目利き / 鮮度 / 地域密着**

### ④ 看板商品（カードグリッド）
```
[ A5ステーキ ][ 特選和牛たたき ][ 和牛切落し ][ 黒豚しゃぶ ]
  写真          写真             写真          写真
  ¥目安         ¥480〜           ¥目安         ¥目安
                [通販で全部見る →]
```
- カードは白背景＋影、写真正方形、価格はゴールド寄り

### ⑤ ギフト 松竹梅（ゴールド基調）
```
背景：オフホワイト＋ゴールド罫線で「特別感」
[🌸 松 極み][🎋 竹 定番][🌿 梅 お試し]
のし・贈答対応の訴求
```

### ⑥ お客様の声（信頼）
- 引用カード（★評価＋コメント＋お名前イニシャル）
- 初出：「★★★★★ 高級A5ステーキ肉、とても美味しかった」

### ⑦ 店舗案内（2店舗・左右分割）
- 各店：写真＋地図＋営業時間＋電話ボタン
- 本店は駐車場「タイムズ銀天町1丁目」案内

### ⑧ メディア・取材実績
- ロゴ／番組名を横並び（TNC ももち浜ストア 等）

### ⑨ Instagram フィード
- 6枚グリッド。`@maruwameat_fukuoka` の世界観で鮮度感を出す

### ⑩ LINE 友だち追加（CTAバナー）
```
背景：和牛レッド／白文字
「特売・新商品・クーポンをLINEでお届け」
[📱 友だち追加] ＋ QRコード
```

## 6. トーン比較（方向性の選択肢）

オーナーの好みで寄せられるよう、2案を想定：

| 案 | 雰囲気 | 向く相手 |
|----|--------|---------|
| **A：上質・モダン** | 白多め＋明朝＋ゴールド。エル三和寄りの洗練 | ギフト・贈答、遠方のお取り寄せ層 |
| **B：元気・地域密着** | 赤強め＋手書き＋写真大。商店街の活気 | ご近所さん、特売ファン |

> 推奨：**A基調 ＋ Bの温かみを部分的に注入**（上質さで信頼を取りつつ、店主の言葉で距離を縮める）

---

## 7. モバイル最適化メモ
- ヒーロー写真は縦長トリミングを別途用意
- CTAは画面下固定（通販／LINE）
- カードは1〜2カラム、タップ領域を大きく
- 電話番号はタップ発信、地図はアプリ起動
