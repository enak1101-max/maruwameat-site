# マル和ミート 通販（EC）比較と設計

| 項目 | 内容 |
|------|------|
| 作成日 | 2026-06-06 |
| 前提 | 通販は「冷凍精肉を主力」。小規模スタート → 反応を見て拡充 |
| 方針 | BASE / STORES / Shopify を比較し1つへ確定。本番は二重運用しない |

---

## 1. プラットフォーム比較（精肉店・小規模スタート観点）

| 項目 | BASE | STORES | Shopify |
|------|------|--------|---------|
| 初期費用 | **0円** | **0円** | 0円 |
| 月額（無料/最小プラン） | 無料プランあり | 無料プランあり | **約4,800円〜**（無料なし） |
| 決済手数料（無料プラン時） | 3.6%+40円＋サービス料3% ≒ **約6.6%+40円** | **5%** | 約3.4%+α（要月額） |
| 月額有料プラン | グロース 月額制で決済 約2.9% | スタンダード 月額2,980円で **3.6%** | ベーシック〜 |
| 開設の手軽さ | ◎ 最短即日・知識不要 | ◎ 直感的・デザイン良い | △ 多機能ゆえ学習コスト |
| デザイン自由度 | ○ | ○〜◎ | ◎（高い） |
| 集客力 | BASE内モール・アプリ流入 | STORESモール | 自前集客が前提 |
| クール便・冷凍対応 | 送料設定で対応（運用は手動） | 同左 | 同左（アプリで拡張可） |
| ギフト/のし | 商品オプションで対応可 | 同左 | 同左（柔軟） |
| 拡張性・将来性 | 中 | 中 | **◎（大規模・多店舗・海外）** |
| 日本語サポート | ◎ | ◎ | ○（英語情報多め） |

> ※手数料率・月額は改定されることがあるため、契約前に各社公式で最終確認。

---

## 2. 推奨

### 結論：**まずは BASE か STORES（無料プラン）でスモールスタート**

理由：
- **初期費用0円・最短即日**で始められ、リスクが小さい
- 精肉店の小規模通販は**機能過多より手軽さ**が正義（在庫・受注をオーナーが回せる）
- 売上が伸びてから、月額有料プランや **Shopify への移行**を検討すればよい

### BASE と STORES の使い分け
- **BASE** … とにかく手軽・BASEアプリからの流入も期待。**最初の一歩に最適**
- **STORES** … デザイン重視・将来予約やPOS連携も視野なら

### Shopify を選ぶなら
- 本格的にブランドECを伸ばす／多店舗・大量商品・将来の海外も視野、という場合
- 月額を払ってでも拡張性・デザイン自由度を取りたいとき

## 3. ホームページとの連携方式

参考サイト（エル三和）も「コーポレートサイト＋別ECストア」構成。同様に：

```
公式サイト（今作っているオレンジのサイト）
   │  「通販で買う」ボタン
   ▼
ECストア（BASE / STORES / Shopify のストアページ）
   → 商品一覧・カート・決済・配送
```

- **方式A（推奨・最速）**：公式サイトの「通販」ボタン → ECストアへ遷移（別ドメイン可）
- **方式B**：公式サイト内に「購入ボタン（埋め込みウィジェット）」を設置（BASE/Shopifyが対応）
- まずは**方式A**で公開 → 慣れたら方式Bで商品を一部サイト内に埋め込み

## 4. 通販ページに必要な要素（チェックリスト）

- [ ] 商品一覧（カテゴリ：ギフト/看板/和牛/豚/冷凍惣菜）
- [ ] 各商品：写真・名称・内容量(g)・価格・**冷凍/冷蔵の明記**・在庫
- [ ] カート・数量変更・決済
- [ ] **送料設定**（地域別 or 一律、○円以上送料無料）／クール便（冷凍）
- [ ] 配送日時指定（ギフトで重要）
- [ ] ギフトオプション（のし・ラッピング・メッセージ）
- [ ] **特定商取引法に基づく表記**（必須）
- [ ] プライバシーポリシー／返品・キャンセル規定
- [ ] 注文確認メール（自動）
- [ ] お問い合わせ導線

## 6. 配送・送料の考え方（要決定）

| 項目 | 案 |
|------|----|
| 配送業者 | ヤマト クール便（冷凍）／佐川 いずれか |
| 温度帯 | **冷凍中心**（品質・在庫管理が安定） |
| 送料 | 地域別 or 全国一律。「○円以上で送料無料」ライン（例：10,000円〜） |
| 梱包 | 保冷剤・緩衝材・保存方法リーフレット同梱 |
| 発送頻度 | 週■回など、無理のない運用に |

---

## 7. 構築ステップ（確定プラットフォーム後）

1. アカウント開設（BASE/STORES/Shopify）
2. 特商法・プライバシー・配送案内ページ作成
3. 商品登録（初回10〜12商品・冷凍精肉中心／写真は撮影済み素材を活用）
4. 送料・決済・ギフトオプション設定
5. テスト注文 → 公式サイトの「通販」ボタンを接続
6. 公開 → LINE / Instagram で告知

---

## 8. 確認事項（オーナー）

1. **プラットフォーム選定**：BASE / STORES / Shopify どれにするか（推奨：BASEまたはSTORES）
2. 月額・手数料の許容ライン
3. 決済手段（カード必須＋α）
4. 配送業者・送料設計
5. 特商法表記の記入情報（責任者名・メール 等）
6. 食肉通販の営業許可の最終確認（冷凍精肉は食肉販売業の範囲が一般的）
