## 1. 開設手順（5分）
1. https://www.linebiz.com/jp/entry/ を開く
2. 「メールアドレスで登録」を選ぶ → お店用Gmailで登録・認証
3. パスワード設定（管理表に記録）
4. アカウント名「**マル和ミート**」／業種「精肉店・食料品」を設定 → 開設完了
5. 「友だち追加QR・URL」を取得 → サイトのLINE枠に設置（連動は制作側で対応）

> まずは**未認証アカウント**で開設 → 落ち着いてから**認証申請**（店名・住所・電話で審査）。
