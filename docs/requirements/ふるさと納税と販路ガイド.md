---

## 1. そもそも「ふるさと納税」って？（超やさしく）

```
寄付する人（全国の消費者）
   │ ① 福岡市に「寄付」する（例：3万円）
   ▼
福岡市（自治体）
   │ ② お礼として「返礼品」を送る（寄付額の3割まで＝約9千円分）
   │   ③ 返礼品はマル和ミートが用意 → 福岡市が代金・送料を払う
   ▼
寄付した人に お肉が届く 🥩
```

ポイント：
- **お店は「福岡市の返礼品提供事業者」になる**と、自社の和牛・豚肉を返礼品として出せる
- **代金・送料は福岡市が負担**（＝お店は売上として受け取る。お店の持ち出しは無し）
- 返礼品は**ふるさとチョイス・ふるなび等のポータルサイト**に掲載 → 全国にPRできる
- ⚠️ 自分のサイトを作っても自動では載らない。**福岡市への申請が別途必要**

## 2. 福岡市への応募（マル和ミートは資格あり✅）

### 応募できる条件
| 条件 | マル和ミート |
|------|-------------|
| 福岡市内に事業所がある | ✅ 博多区に2店舗 |
| 福岡市内で生産・製造・**加工**された地場産品 | ✅ 市内で精肉加工（博多和牛など福岡産だと尚良し） |

### 申込みの流れ（3ステップ）
1. **募集要項を確認**（[福岡市ふるさと納税 返礼品募集ページ](https://fukuoka-furusato.jp/bosyu/)）
2. **書類3点を提出**
   - 誓約書（様式1）
   - 役員名簿（様式2）
   - 市町村税納税証明書（発行日前3ヶ月以内のもの）
3. **申込フォーム提出**（返礼品の写真データを添付）→ 審査

### 費用・スケジュール
- 💰 **事業者負担なし**（返礼品代金・送料は福岡市が負担）
- 📅 **随時受付中**。ただし市の審査＋総務省・福岡県の確認で**相当期間**かかる（早めの応募が吉）

### 問い合わせ先（福岡市の運営委託先）
- **レッドホースコーポレーション株式会社**
- TEL：0120-428-044（平日 9:00〜17:30）
- フォーム：https://www.redhorse.co.jp/c_furusato_b/

## 3. 返礼品の候補＆寄付金額の設計（3割ルール）

### ルール：返礼品は「寄付額の3割」まで
> 返礼品の価格（お店が受け取る額）＝ 寄付額 × 30% が上限
> 逆算すると **寄付額 ＝ 返礼品の価格 ÷ 0.3**

### マル和ミートの返礼品プラン例（仮）

| 返礼品（案） | 返礼品の価格目安 | 設定する寄付額の目安 |
|--------------|-----------------|---------------------|
| ブランド豚 しゃぶしゃぶ 500g | 約3,000円 | **10,000円** |
| 博多和牛 ハンバーグ 4個 | 約3,000円 | **10,000円** |
| 和牛 切り落とし 500g | 約4,000円 | **14,000円** |
| 和牛 焼肉セット | 約5,000円 | **17,000円** |
| 和牛 すき焼き 600g | 約9,000円 | **30,000円** |
| A5和牛 ステーキ詰合せ | 約15,000円 | **50,000円** |

> ※金額はすべて仮。実際は原価・採算・送料（市負担）を踏まえて設定。
> ※冷凍クール便で全国配送できる商品が中心になる（自社通販と同じ考え方）。

### 売れ筋になりやすいのは
- **1万円台の手頃な返礼品**（初めての寄付者が選びやすい）
- **3万円前後のすき焼き・焼肉セット**（ボリューム感で人気）
- ギフト感のある化粧箱入りは満足度が高い

## 4. 自社通販の始め方（いちばん現実的なルート）

> ふるさと納税やモール出店の「土台」になるのが自社通販。まずここを整える。

### おすすめ：BASE で無料スタート（初心者向け）

| ステップ | 内容 | 誰が |
|---------|------|------|
| 1 | BASEアカウント開設（無料・メールだけ） | お店 or 制作側で代行 |
| 2 | 特商法・配送・返品ページ作成 | 制作側がひな形提供 |
| 3 | 商品登録（写真は提供済み素材を活用・10〜12点） | 制作側が代行可 |
| 4 | 送料設定（冷凍クール便・○円以上送料無料） | 一緒に決める |
| 5 | 決済設定（カード・コンビニ・PayPay等） | 設定するだけ |
| 6 | テスト注文 → 公式サイトの「通販」ボタンと接続 | 制作側 |
| 7 | 公開 → LINE・Instagramで告知 | お店 |

### なぜBASEから？
- 初期費用・月額が**0円**（売れた分だけ手数料）でノーリスク
- 操作が簡単・日本語サポート
- ここで整えた**商品・写真・配送体制**が、そのまま**ふるさと納税や楽天等の出店にも流用できる**

---

## 5. 全体の流れ（これからの道のり）

```
① 自社サイト＋通販(BASE)を整える  ← いまココを構築中
        │  （商品・写真・配送・特商法が揃う）
        ▼
② その素材を使って横展開
        ├─ ふるさと納税（福岡市に申請）
        ├─ 楽天市場 / Yahoo! / Amazon
        └─ 食べチョク等の産直モール
```

→ **まず自社の「本拠地」を作る → そこから各販路へ広げる**のが王道です。

---

## 6. 当面のおすすめアクション

1. **自社通販（BASE）の構築を進める**（最優先・土台づくり）
2. 並行して、**福岡市ふるさと納税の募集要項を取り寄せ＆書類準備**（審査に時間がかかるので早めに）
3. 返礼品の品目・寄付額をオーナーと相談して確定
4. 通販公開後、ふるさと納税・モールへ順次展開

---

*ふるさと納税の制度・返礼率ルールは国の方針で変わることがあります。最終確認は福岡市（レッドホース）窓口で。*
