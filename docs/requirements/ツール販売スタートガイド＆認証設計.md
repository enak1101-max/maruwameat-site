## A. パスワード＋規約でスタートする「やり方」

### ステップ1：パスワードを設定
- ビルダーの中に `var PASSWORD="Enak2026";` という行があります（現在のパスワード＝**Enak2026**）。
- ここを書き換えれば、好きなパスワードに変更できます。
- 💡 **購入者ごとに別パスワード**にすると、「誰が漏らしたか」が分かり管理しやすいです（例：購入者Aには `A-x7k2`、Bには `B-9m4p`）。

### ステップ2：利用規約（ライセンス文）を用意（下の B をコピペ）
- 「1人／1店舗のみ使用可」「再配布・転売禁止」などを明記。
- 購入時に**同意してもらう**（販売ページに記載・チェックボックス）。

### ステップ3：販売する
ダウンロード販売サービスを使うのが簡単です：
- **BOOTH**（pixiv）／**Gumroad**／**note** など
- 商品＝「builder.html ＋ 取扱マニュアル(PDF) ＋ 利用規約」を **zip** にして登録
- 価格は「販売パッケージ化・公開ガイド」参照（買い切り ¥9,800〜29,800 等）

### ステップ4：購入者に渡すもの
1. ツール本体（builder.html）※その人専用パスワード入り
2. 取扱マニュアル（編集→書き出し→公開の手順）
3. 利用規約（ライセンス文）

### ⚠️ この方式の限界（正直に）
- パスワードは教え合えば共有できます＝**技術的には1人限定を強制できません**。
- 「**規約で禁止（法的な縛り）＋簡易ロック**」での抑止が現状の上限。
- 本格的に守るなら → **C のログイン認証**へ。

## B. 利用規約（ライセンス文）ひな形 ※そのままコピペ可

```
【ホームページビルダー 利用規約（ライセンス）】

第1条（ライセンスの付与）
　本ツールは、購入者ご本人（1名／1事業者）のみが使用できる
　非独占的ライセンスです。

第2条（禁止事項）
　購入者は、以下の行為を行ってはなりません。
　1. 本ツールおよびパスワードの第三者への共有・貸与・譲渡・再配布
　2. 本ツールの転売・再販売
　3. 本ツールの内容を複製し、別ツールとして配布する行為
　4. 著作権表示の削除・改変

第3条（許可される利用）
　購入者は、自身（または自社）のホームページ制作の目的で、
　回数無制限で本ツールを使用し、成果物を公開できます。

第4条（サポート・保証）
　本ツールは現状有姿で提供されます。動作環境により
　一部機能が動作しない場合があります。

第5条（免責）
　本ツールの使用により生じたいかなる損害についても、
　販売者は責任を負いません。

第6条（規約違反）
　本規約に違反した場合、ライセンスは即時失効し、
　使用の停止を求めることがあります。

発行：〈販売者名〉　／　お問い合わせ：〈連絡先〉
```

## C.【将来】ログイン＋ライセンス認証 の設計図（1アカウント限定）

売上が伸びたら、「買い切り・無制限編集・1アカウントのみ」を**技術的に強制**する仕組みへ。

### 全体構成
```
購入者
  │ ① 購入（Gumroad/BOOTH等）→ ライセンスキー発行
  ▼
ビルダー（builder.html）
  │ ② 起動時にログイン or ライセンスキー入力
  ▼
認証サーバー（Firebase / Supabase など 無料枠あり）
  │ ③ キーが有効か・そのアカウントのものか確認
  │ ④ 同時利用・端末数をチェック（共有を検知）
  ▼
  OK → 編集可能／NG → ロック
```

### 必要なもの
| 要素 | 役割 | 候補サービス |
|------|------|-------------|
| 認証（ログイン） | 購入者ごとのアカウント | Firebase Authentication / Supabase Auth |
| ライセンス管理 | キーの発行・有効/無効・紐付け | Firestore / Supabase DB |
| 販売＋キー発行 | 購入時に自動でキー発行 | Gumroad（ライセンスキー機能）/ Stripe |
| 共有検知 | 同時ログイン・端末数の制限 | サーバー側でセッション管理 |

### 認証の流れ（実装イメージ）
1. 購入 → メールでライセンスキー（例：`XXXX-XXXX-XXXX`）が届く
2. 初回起動：キー入力＋メール登録 → そのキーを**1アカウントに固定（アクティベーション）**
3. 以降：ログインすれば編集可能。別の人が同じキーを使うと**「既に使用中」で拒否**
4. 端末追加は「○台まで」と上限設定（家・スマホ等の正規利用は許容）

### 開発規模の目安
- 小規模（Firebase/Supabase の無料枠）で**スモールスタート可能**
- ビルダー側に「ログイン画面＋認証チェック（数十行のJS）」を追加
- 販売はGumroadのライセンスキー機能と連携すると最短

### 進め方
1. まずは **A（パスワード＋規約）で販売開始**（コスト0・すぐ）
2. 売れ行き・不正共有が見えてきたら **C（ログイン認証）を実装**
3. 既存の買い切りモデルは維持（認証はあくまで「1人だけ」を守るため）

> ※実装段階になったら、Firebase/Supabaseのどちらか選定 → ログイン画面とライセンス確認APIを組み込みます。設計はこの図のとおり進められます。
