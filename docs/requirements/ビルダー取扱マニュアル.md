# ホームページビルダー 取扱マニュアル

| 項目 | 内容 |
|------|------|
| 対象 | 本ツール（builder.html）でホームページを作る方 |
| できること | 文字・画像・色を自由に編集 → 規約まで自動作成 → 完成HTMLを書き出し → 無料で公開・更新 |
| 最終更新 | 2026年6月8日（自動保存・郵便番号・アイキャッチ・業種別規約・公開/更新/削除 を追加） |

---

## 1. ひらき方
1. `builder.html` をブラウザで開く（スマホでもOK）
2. **パスワード**を入力 →「解除する」
3. 古い画面が出る時は **`⌘+Shift+R`（Mac）／`Ctrl+Shift+R`（Win）** で最新版に

---

## 2. 編集のしかた（ノーコード）

### ✏️ 文字
- 変えたい文字を**クリック → そのまま打ち替え**（消したい時は全選択して削除）
- クリックすると上に**ミニツールバー**（A− 小さく／A＋ 大きく／B 太字／↺ 戻す／色）が出ます
- キャッチコピー・見出し・英語ラベル（FEATURES等）・紹介文、ほぼ全部の文字が編集可
- ※ヘッダーの「店名」は直接クリックではなく、「店舗案内」の**店名欄**から（全体に自動反映）

### 🖼️ 画像
- 画像枠を**タップ → 端末から写真を選ぶ**だけ
- **アップした画像は自動で軽量化**されます（保存・公開が軽くなる）
- 推奨：ロゴ512×512px／商品800×800px／紹介1200×900px

### ⭐ トップのアイキャッチ画像（画面いっぱい・任意）
- 🎨パネル →「🖼️ 画面いっぱいの画像を選ぶ」
- **透明度スライダー**で濃さ調整（左=薄く文字くっきり／右=画像くっきり）
- 「画像を外す」で元の色背景に戻る（未使用なら従来どおり）

### 🏪 お店の情報（店舗案内に入力 → 全体に自動反映）
「店舗案内」の欄に入れると、ヘッダー・フッター・地図・規約まで自動反映。
- **店名** → ロゴ横・フッター・タブのアイコン（ファビコン）に反映
- **責任者** → 特商法の「運営責任者」に反映
- **郵便番号** → 入力すると**住所が自動入力**（番地・建物名を追記）
- **住所** → 入力するだけで**地図が自動表示**
- 電話・メール・業種 → フッターや規約に反映
- SNSリンク → **入れたものだけ**フッターに表示（LINEは友だち追加ボタンにも連動）

### 🔖 アイコン（ファビコン）
- **ロゴ横の丸いマークをタップ → アイコン画像を選ぶ**
- → ブラウザのタブのアイコン（ファビコン）も自動で同じ画像になります

### 🎬 画像 / 動画
- 「画像（推奨）」か「動画（YouTube）」を選択。動画はYouTubeリンクを貼るだけ

### ➕ 商品・お客様の声・強み
- 「＋ 追加」で増やす／各カードの「✕」で削除
- レビューの**星はクリックで評価変更**（大きめで押しやすい）

### 🎨 デザイン（右下の🎨ボタン／✕で閉じる）
- テーマ色・色の濃さ・フォント・角丸・余白・文字サイズ
- 表示するセクションのON/OFF
- 文字サイズスライダーは見出し・紹介文にも連動

### 📱 PC / スマホ プレビュー（上部のボタン）
- 「💻PC」「📱スマホ」で表示を切替（**ビルダー内で見るための機能**）
- ※書き出すサイトは**自動でスマホ対応**します。PC状態のまま書き出してOK

---

## 3. 保存（作りかけを残す）
### 自動保存（同じ端末）
- 編集すると**自動でこの端末に保存**（🎨パネルに「✓自動保存しました」）
- → 閉じても、**同じ端末・同じブラウザで開き直せば続きから**

### 作業ファイルで端末またぎ（スマホ→PC など）
- 🎨パネル →「💾 作業ファイルを書き出す」→ `mysite-project.json` が保存される
- それを相手の端末に送り（AirDrop/メール/クラウド）→「📂 作業ファイルを読み込む」→ **続きから編集**
- ルール：**作業した端末で“最新”を書き出して渡す**（古いファイルは使い回さない）
- 「🗑️ 保存を消して最初から」でリセット

---

## 4. 規約の設定（業種を選ぶだけ）
1. 画面下の **「次へ（規約設定）」**
2. 店名・住所・連絡先は自動反映 → **業種をプルダウンで選ぶ**
3. **業種別の専門的な規約**が自動作成（プライバシー／キャンセル返品／特商法）
   - 対応業種：飲食・カフェ・美容・整体・小売・食品・教室・医療・宿泊・**建築・外壁塗装・外構・士業・占い/スピリチュアル**・その他
   - 特商法の**価格・支払い方法・費用**も業種ごとに変わる（例：建築＝銀行振込/現金/ローン・お見積もり）
4. 規約は**クリックで直接編集・追記**できます（調べた内容を足してもOK）

---

## 5. 書き出し（完成HTMLを保存）
1. 「📦 公開用に書き出す（HTMLダウンロード）」を押す
2. `mysite.html` がダウンロード（編集UIを外した公開用ファイル）
   - **未入力（〈　〉）の項目は自動で非表示**／タブ名は店名／黒縁なし、で書き出されます

---

## 6. 公開する（無料・Netlify）
### A. 初めて公開する
1. `https://app.netlify.com/drop` を開く
2. `mysite.html` を**ドラッグ＆ドロップ** → 仮URL発行
3. 無料アカウント作成（**Sign up for free**）→ **1時間制限・パスワードが解除**され永久公開
4. （任意）「Change project name」でURLをキレイな名前に

### B. 既に公開したサイトを更新（同じURLのまま上書き）★重要
1. ビルダーで編集 → 📦 書き出し（新しい `mysite.html`）
2. Netlifyで**そのプロジェクトを開く** → 左メニュー **「デプロイする」**
3. 「Need to update your project?」の枠に**新しいファイルをドラッグ**
4. **「index.htmlに名前を変更しますか？」→ 必ず「名前を変更してデプロイ」** ← これ重要！
5. → 同じURLのまま中身が更新🎉
- ⚠️ `app.netlify.com/drop`（最初の画面）に落とすと**別URL**になる。更新は**既存プロジェクトのデプロイ**へ

### C. 失敗サイトを削除して名前を再利用
1. 削除したいサイトを開く →「プロジェクト構成」→ 下の **「Danger zone」**
2. **「Delete this project」** → 名前を入力して削除
3. → その名前（URL）が再び使えるようになる
- ⚠️ **本番サイトは削除しない！**（テスト・失敗のものだけ）

## 7. よくあるトラブルと対処
| 症状 | 原因 | 対処 |
|------|------|------|
| 公開サイトが「ページが見つかりません(404)」 | ファイル名が index.html でない | 再デプロイ時に**「名前を変更してデプロイ」**を選ぶ |
| 更新が画面に出ない | ブラウザのキャッシュ | `⌘+Shift+R`、またはURL末尾に `?2` `?3`… |
| タブのアイコンが白い | アイコン未設定／古い書き出し | ロゴ丸をタップしてアイコン設定 → 書き出し → デプロイ |
| スマホでPC表示に見える／ヘッダー崩れ | 最新版で書き出していない | 最新版（⌘+Shift+R）で書き出し直して再デプロイ |
| 〈　〉の枠が本番に残る | 未入力のまま | 最新版で書き出せば空欄は自動非表示（入れたものだけ表示） |
| 復元したのに戻らない | 画像が大きすぎ等 | 最新版で読み込み直す（画像は自動軽量化されます） |
| 作業が消えた | 別端末で開いた | 自動保存は端末ごと。端末またぎは「作業ファイル」で |

---

## 8. 注意
- 規約の文面は**たたき台**です。公開前に内容をご確認ください（特に返品条件）。
- 同じURLで更新したい時は、必ず**既存プロジェクトの「デプロイする」**から。
- 端末をまたぐ時は**作業ファイル（json）**を持っていく（自動保存は端末ごと）。
