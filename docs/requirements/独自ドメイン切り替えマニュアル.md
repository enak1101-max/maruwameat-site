## 1. 独自ドメインとは／メリット
- 自分専用のキレイな住所（例 `maruwameat.jp`）
- 覚えやすい・名刺やチラシに載せやすい・信頼感が上がる
- **一度取れば、サイトの中身はそのまま**で住所だけ変わる

## 2. 費用の目安（年額）
| ドメイン | 目安 | 備考 |
|----------|------|------|
| `.jp` | 約 ¥2,000〜4,000／年 | 日本の信頼感◎・人気 |
| `.com` | 約 ¥1,500〜2,000／年 | 世界標準・安い |

※ ドメインは「**毎年の更新料**」がかかります（買い切りではない）。自動更新ONにしておくと失効防止に。

## 4. 取得後の接続手順（GitHub Pages の場合）

> 難しく見えますが、やることは「**ドメイン会社の管理画面で、決められた数字を5行コピペする**」だけです。
> ここが一番の山場なので、画面操作まで細かく書きます。分からなければ ENAK が代行します。

### 🧭 そもそもDNSとは？（イメージ）
DNS＝「**住所の案内係**」です。
`maruwameat.jp` と打った人を、サイトの実体がある GitHub の場所へ案内します。
その「案内先のメモ（レコード）」を、ドメイン会社の管理画面に登録する作業です。

登録するメモは全部で **5行**（下の表）。これを各社の画面に入れるだけ。

| # | 種類(TYPE) | ホスト/サブドメイン | 値(VALUE) |
|---|-----------|----------------------|-----------|
| 1 | A | @（空欄） | 185.199.108.153 |
| 2 | A | @（空欄） | 185.199.109.153 |
| 3 | A | @（空欄） | 185.199.110.153 |
| 4 | A | @（空欄） | 185.199.111.153 |
| 5 | CNAME | www | enak1101-max.github.io |

- 「ホスト/サブドメイン」が **@ か 空欄** = ドメインそのもの（maruwameat.jp）を指します。会社により「@」だったり「空欄」だったりします。
- CNAMEの値の最後にドット有り（`enak1101-max.github.io.`）を求める会社もあります。エラーが出たら付けて再試行。

---

### STEP A-1. 【お名前.comの場合】の画面操作
1. **お名前.com Navi** にログイン（`navi.onamae.com`）
2. 上メニュー **「ドメイン」** → **「DNS関連機能の設定」**
3. 対象ドメイン（maruwameat.jp）に **チェック** → **「次へ」**
4. メニューから **「DNSレコード設定を利用する」** の **「設定する」**
5. **Aレコードを1行ずつ追加**（下を4回くり返す）:
   - ホスト名:**空欄**　/　TYPE:**A**　/　VALUE:**185.199.108.153**　→ **「追加」**
   - 同様に `.109.153` `.110.153` `.111.153` も追加（計4行）
6. **CNAMEを1行追加**:
   - ホスト名:**www**　/　TYPE:**CNAME**　/　VALUE:**enak1101-max.github.io**　→ **「追加」**
7. 下の **「確認画面へ進む」** → **「設定する」** で保存

---

### STEP A-2. 【ムームードメインの場合】の画面操作
1. **ムームードメイン** のコントロールパネルにログイン
2. 左メニュー **「ドメイン操作」** → **「ムームーDNS」**
3. 対象ドメインの **「変更」** をクリック
4. **「カスタム設定」** の **「セットアップ情報変更」**
5. **「設定2（当サービス以外をご利用の場合）」** の独自レコード欄に入力:
   - サブドメイン:**空欄**　/　種別:**A**　/　内容:**185.199.108.153**
   - 同様に `.109.153` `.110.153` `.111.153`（計4行）
   - サブドメイン:**www**　/　種別:**CNAME**　/　内容:**enak1101-max.github.io**
6. **「セットアップ情報変更」** ボタンで保存

---

### STEP A-3. 【その他の会社（Cloudflare/Xserver等）の場合】
画面の名前は違っても、**入れる中身は同じ5行**です。
「DNS設定」「ネームサーバー内のレコード編集」等のメニューを探し、上の表の5行を追加してください。
（Cloudflareの場合、Aレコードの「Proxy（オレンジの雲）」は **OFF（グレー）** にする）

---

### STEP B. GitHub側で独自ドメインを登録
※ この作業は **ENAK（制作側）が行います**。オーナー様はドメインを取ってDNSを入れるところまででOK。
1. GitHubのリポジトリ `enak1101-max/maruwameat-site` を開く
2. **Settings → Pages**
3. **Custom domain** に `maruwameat.jp` を入力 → **Save**
4. （自動で `CNAME` ファイルがリポジトリに追加されます）
5. 「DNS check successful」と出たら、**「Enforce HTTPS」にチェック**（鍵マーク＝暗号化）

---

### STEP C. 反映を待つ・確認する
- DNSの反映に **数十分〜最大48時間**かかることがあります（たいてい1時間以内）
- 確認サイト `https://www.whatsmydns.net/` でドメインを検索すると、世界中で反映されたか見られます
- ブラウザで `https://maruwameat.jp` を開いてサイトが出ればOK 🎉

---

### 🔧 うまくいかない時（チェック）
| 症状 | 対処 |
|------|------|
| サイトが出ない | まだ反映待ち。1〜数時間待つ。whatsmydnsで確認 |
| 「保護されていない通信」と出る | HTTPS有効化前。STEP B-5の「Enforce HTTPS」を待つ／押す |
| CNAMEでエラー | 値の最後にドット `enak1101-max.github.io.` を付けて再試行 |
| www有り無しの片方で出ない | Aレコード4つ＋wwwのCNAME、両方入っているか確認 |
| GitHubで「DNS check」が赤い | DNS反映待ち。時間をおいて再度Save |

## 5. ⚠️ 切り替え後に「変更が必要な場所」チェックリスト
URLが変わるので、古いURLを書いている所を新URLに直します。

- [ ] サイト内の **OGP設定**（`og:url` / `og:image`）→ 新ドメインに
- [ ] サイト内の **構造化データ**（`url` / `image`）→ 新ドメインに
- [ ] **ポートフォリオ（ENAK）** のマル和へのリンク
- [ ] **QRコード**を新URLで作り直す（チラシ・店頭用）
- [ ] **Instagramのプロフィールリンク**
- [ ] **Googleマップ／各種登録**にHPを載せている場合
- [ ] **BASE**のSNS欄など、HPを載せている箇所
- [ ] 名刺・チラシ等の印刷物

> 💡 サイト内（OGP・構造化データ）の書き換えは**ENAK（制作側）で対応**します。オーナー様は印刷物・SNSの差し替えだけでOK。

---

## 6. よくある注意点
- **古いURLも当分は生きています**（github.ioはそのまま動く）。慌てて消さない
- **HTTPS（鍵マーク）** が付くまで少し時間がかかる。付くまで待つ
- `www あり/なし` はどちらかに統一（上の設定で両対応にしてあります）
- ドメインの **更新料の払い忘れに注意**（失効するとサイトが見られなくなる）→ 自動更新ON推奨

---

## 7. 補足：通販（BASE）の独自ドメインは別もの
- ホームページ（GitHub Pages）の独自ドメインと、**BASEストアの独自ドメインは別**です
- BASEを独自ドメイン（例 `shop.maruwameat.jp`）にするには、**BASEの「独自ドメイン」App（有料／グロースプラン）**が必要
- 通常は **HP＝独自ドメイン／BASE＝base.shopのまま**で十分。HPの通販ボタンから飛べるのでお客様は困りません

---

## 8. 迷ったら
独自ドメインを取る段になったら、**ドメイン名の候補・購入先・DNS設定・サイト側の書き換え**まで、ENAK（制作側）でサポート／代行できます。オーナー様は「このドメインにしたい」と決めるだけでOKです。
