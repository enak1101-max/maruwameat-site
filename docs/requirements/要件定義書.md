## 1. プロジェクト概要

福岡県福岡市博多区で精肉店を営む「**マル和ミート**」（雑餉隈本店・月隈店の2店舗）の
公式ホームページを新規制作する。あわせて以下を実現する。

1. **ホームページ上での通販（EC）機能** の組み込み
2. **LINE公式アカウント（新規開設）** との連動
3. 既存 **Instagramアカウント（店舗・社長）** との連動

参考サイトである [エル三和](https://elsanwa.com/) の「お肉のプロが手がける、こだわりの精肉店」
というブランド表現・清潔感のあるデザインを踏襲しつつ、地域密着の親しみやすさを加える。

## 4. サイト構成（サイトマップ）

参考サイト（エル三和）の構成をベースに、精肉店の「お店」性格を強めた構成とする。

```
TOP（トップページ）
├── お店紹介 / こだわり        … 鮮度・仕入れ・品質へのこだわり、店主の想い
├── 商品紹介                   … 和牛 / 黒豚 / 惣菜・加工品 など取扱商品
├── 通販（オンラインストア）    … EC機能（別ドメイン or 埋め込み）
├── 店舗案内                   … 雑餉隈本店 / 月隈店（地図・営業時間・駐車場）
├── メディア・取材実績          … TNC取材ほか
├── お客様の声 / 実食レビュー    … 実食コメント、星評価、写真付きレビュー
├── お知らせ / ブログ          … Instagram連動、特売・休業案内
├── よくある質問（FAQ）        … 通販・配送・支払い等
└── お問い合わせ              … フォーム / 電話 / LINE
```

各ページ共通要素：
- ヘッダー：ロゴ、グローバルナビ、通販ボタン（CTA）、LINE/Instagramアイコン
- フッター：2店舗の情報、SNSリンク、地図、コピーライト、各種ポリシー
- 追従CTA（モバイル）：「通販で買う」「LINEで友だち追加」

### 5.6 業務用・卸（B2B受発注）※新規要件

> 現状、居酒屋など飲食店への卸注文を **FAX・電話** で受けている。これをデジタル化したい。

| ID | 機能 | 要件 |
|----|------|------|
| FR-50 | 取引先限定の注文画面 | 会員制／パスワード保護で、登録した飲食店だけが**卸価格**で注文できる |
| FR-51 | かんたん発注 | 定番商品をリピート発注しやすく（FAX/電話の置き換え） |
| FR-52 | 受注通知 | 注文が入ったら店舗へ通知（メール/LINE） |
| FR-53 | 掛け払い対応 | 月締め請求（掛売）に対応 ※一般的なBtoC ECでは弱点 |
| FR-54 | 取引先別価格 | 取引先ごとに単価が違う場合に対応 ※同上 |

#### 実現方式の比較（重要）
| 方式 | FAX/電話の解消 | 取引先別価格 | 掛け払い | コスト | 向き |
|------|:---:|:---:|:---:|------|------|
| **STORES/BASE（会員制・パスワード保護）** | ◯ | △ | ✕（弱い） | 低 | まず脱FAXするだけなら可 |
| **会員制 注文フォーム / LINE注文** | ◎ | △ | （請求は従来どおり月締め） | **最低** | **最速・現実的な第一歩** |
| **BtoB受発注システム（Bカート等）** | ◎ | ◎ | ◎ | 中〜高 | 取引先・品目が多く本格化する場合 |

#### 結論・方針（更新：費用許容＋シンプル重視）
- **B2C通販（一般客）とB2B卸（飲食店）は別システムに分ける**（価格も決済も別物）
- 卸については **BASE・STORESは同等に不向き**（掛け払い・取引先別価格が弱い）
- **オーナー意向＝費用をかけても配送・決済がシンプルで分かりやすい環境** → **卸専用「Bカート」を推奨**
  - 月額9,800円〜。**掛け払い（月末締め請求）／取引先別価格（一物多価）が標準**
  - 「飲食店からのFAX・電話注文をネット化」という用途にそのまま合致
- 理想構成：公式サイト ＋ 一般通販(BASE/STORES) ＋ 卸(Bカート)。サイト上で入口を分ける
- ※最小コストで脱FAXだけなら「会員制注文フォーム / LINE注文」も選択肢（請求は従来どおり月締め）

### 必須確認（要件確定に直結）
1. ~~両店舗の正式な営業時間・定休日・駐車場~~ → ✅**両店確定**。本店=9:30〜19:00／1/1〜1/4休／駐車場無（近隣タイムズ）。月隈店=10:00〜19:00／日曜＋1/1〜1/4休／駐車場有

6. **食品の許認可**：通販に必要な営業許可の確認。管轄＝**福岡市保健所（博多区）**で要確認
   - 冷凍精肉の通販 … 既存の **「食肉販売業」許可**の範囲で対応可が一般的（ハードル低・第1弾向き）
   - **惣菜（コロッケ・メンチ等）の通販** … **「そうざい製造業」の許可＋製造施設基準** が別途必要（第2弾向き）
   - ハム・ソーセージ等 … **「食肉製品製造業」** が必要な場合あり
   - 全事業者共通：**HACCPに沿った衛生管理**（2021改正で義務化）、通販包装品の**食品表示**、冷凍食品の温度管理
   - ※上記は一般情報。最終判断は保健所相談で確定する
