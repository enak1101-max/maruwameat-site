# ホームページビルダー 販売パッケージ化・公開ガイド

| 項目 | 内容 |
|------|------|
| 作成日 | 2026-06-06 |
| 対象 | builder.html（ノーコードHPビルダー）を「ツールとして売る／公開する」ための整理 |

---

## 1. 販売可能な状態にパッケージ化できる？ → ほぼYES（あと1機能）

ビルダーは **単一のHTMLファイル**（外部依存はGoogleフォントのみ）なので、配布・パッケージ化は簡単です。ただし**売る前にもう1つだけ必要な機能**があります：

> ⭐ **「書き出し（完成HTMLを保存）」機能**
> 今のビルダーは編集が「その場限り（保存されない）」。買った人が**自分のサイトを作って公開できる**ように、編集結果を**1枚の完成HTMLとしてダウンロード**する機能を足す必要があります。
> → これを足せば「販売可能な状態」になります（実装可能。次のステップ）。

---

## 2. ホームページに「ドメイン」は必要？

混同しやすいので、まず2つを分けて理解します。

| | 役割 | 例 | 必須？ |
|---|------|----|--------|
| 🏠 **ホスティング**（置き場所） | ファイルをネットに置いて公開する場所 | Netlify / Cloudflare Pages / GitHub Pages | **必須**（公開には必要） |
| 🌐 **ドメイン**（住所＝URL） | 覚えやすい独自のアドレス | yourshop.com | **任意**（無くてもOK） |

### 結論
- **公開するだけなら「無料サブドメイン」でOK**（例：`yourshop.netlify.app`）。**独自ドメインは無くても公開できます。**
- **独自ドメイン（yourshop.com）は「信頼感・覚えやすさ・ブランド」のために推奨**。年 約1,000〜4,000円。

## 3. 【マニュアル】ドメイン取得 → 設置（公開）の手順

### ステップ0：完成ファイルを用意
ビルダーで編集 → **「書き出し」で完成HTMLをダウンロード**（＋画像フォルダ）。

### ステップ1：ホスティングに設置（まず無料で公開）
いちばん簡単なのは **Netlify Drop**：
1. `https://app.netlify.com/drop` を開く
2. 完成フォルダを**ドラッグ＆ドロップ**
3. → 即公開！ `https://◯◯◯.netlify.app` のURLが発行される
   （※同様に Cloudflare Pages / GitHub Pages でも可）

この時点で**無料URLで公開完了**。独自ドメインが不要ならここで終わりでもOK。

### ステップ2：独自ドメインを取得（任意）
ドメイン取得サービスで好きなURLを購入：
- **お名前.com** / **ムームードメイン** / **Cloudflare Registrar**（原価に近く安い）
- 手順：希望のドメイン名を検索 → 空いていれば購入（年額・クレカ）

### ステップ3：ドメインをホスティングに接続
1. ホスティング側（例：Netlify）の管理画面で「**カスタムドメインを追加**」
2. 取得したドメインを入力
3. 案内に従って**DNS設定**（下記のどちらか）
   - **ネームサーバーを変更**（Netlifyのネームサーバーを指定）＝おすすめ・簡単
   - or **CNAME/Aレコード**をドメイン側に追加
4. 保存 → **反映を待つ**（数分〜最大48時間／通常はすぐ）

### ステップ4：SSL（https）
- Netlify等は**自動でSSL（https）が付く**ので、設定後しばらくで `https://yourshop.com` が有効に。

### ⚡ いちばんラクなルート（おすすめ）
**Netlifyで「ドメイン購入〜接続」まで一括**でできます（Netlify上でドメインを買えば、DNS設定が自動）。初心者には最短です。

### ⚠️ 注意点
- DNSの反映には時間差あり（焦らず待つ）
- `www有り/無し` の統一設定をしておく
- ドメインは**毎年更新**（自動更新ONにし忘れに注意）

## 4. ツールとして販売：価格の目安

ビジネスモデルで適正価格が変わります。

| モデル | 内容 | 価格の目安 |
|--------|------|-----------|
| 💿 **買い切りツール販売** | 個人/小規模店が**自分で**使うツールとして販売 | **¥9,800〜¥29,800**（買い切り） |
| 🛠️ **制作代行に活用**（おすすめ） | あなたがツールで**代行制作して納品** | サイト制作 **¥50,000〜¥200,000**（松竹梅見積もり参照） |
| ☁️ **SaaS／月額** | ホスティング・保存込みで継続課金 | 月 **¥1,000〜¥5,000**（ペライチ/Wix系の相場） |
| 🏷️ **白ラベル/ライセンス** | 他の制作業者へ提供 | **¥50,000〜数十万** ＋ ロイヤリティ |

### 市場の現実と、おすすめの落とし所
- ノーコードHP/EC市場は **Wix・STUDIO・ペライチ・BASE** など強力な競合（無料〜月額）が多い。**ツール単体の買い切り販売は差別化が必要**。
- **いちばん収益化しやすいのは「制作代行の武器」**として使う形：
  - お客様から **サイト制作 5〜20万円**で受注 → **このビルダーで爆速制作・納品** → 利益率が高い
  - ＝ ツールは「あなたの営業・制作スピードを上げる秘密兵器」。これが現実的に一番強い。

## 5. 納品形態（データの形態）

| 納品物 | 形態 |
|--------|------|
| 完成ホームページ | **HTMLファイル1枚 ＋ 画像フォルダ**（zip） |
| ツール本体（売る場合） | **builder.html ＋ 取扱マニュアル(PDF) ＋ ライセンス文** を zip でダウンロード納品 |
| 公開込みで納品 | ホスティングに設置して**公開URLを渡す**（独自ドメイン接続まで代行も可） |

### 納品の流れ（制作代行の場合）
1. ビルダーで制作 → 書き出し（HTML一式）
2. ホスティングに設置・独自ドメイン接続
3. **公開URL・管理情報・簡単マニュアル**をお客様に引き渡し（→「代理セットアップ＆引き渡しマニュアル」参照）

3. ライセンス文（利用規約）作成
