## 2. ホームページの編集（自分でできる）
### 編集モードの入り方
1. URLの最後に **`?edit`** を付けて開く
   → `https://maruwameat.com/?edit`
2. パスワード **`Enak2026`** を入力

### 編集する
- **文字**：クリックして打ち替え
- **画像**：写真をタップ → 端末から差し替え

### 反映（公開）する
- 保存した `index.html` を **ENAK に送る**（ENAKが公開に反映）

- 編集は**保存するまで反映されない**

## 3. BASE（通販）の操作
### ログイン
`https://admin.thebase.com` → メールでログイン

### 商品を追加する
1. アドレスバーに `admin.thebase.com/shop_admin/items/add`（または左メニュー「商品」→「商品を登録」）
2. **画像**をアップロード
3. **商品名・価格・説明文**を入力
4. **在庫数**を入力（売り切れ防止なら 1）
5. **税率＝8%（軽減税率）**（食品は8%）
6. 「登録する」

### 商品を編集・削除・非表示
- 左メニュー「商品」→ 該当商品をクリック → 編集／削除
- 一時的に隠す＝「公開状態」をOFF

### 送料を変える
- 「設定」→「配送方法」→ 地域別の金額を編集
- 現在：80サイズ基準＋箱代込み（九州¥1,610〜北海道¥3,000・沖縄¥2,320）※資料室「送料表」参照

### 特商法・インボイスの場所
- 「設定」→「特定商取引法」／「インボイス設定」
- 事業者名：株式会社マル和ミート ／ インボイス：T6290001057030

### デザインを変える
- アドレスバー `admin.thebase.com/shop_admin/design`（または左メニュー「デザイン」）
- テーマ＝和モダン。メイン画像・キャッチコピー・色を編集 → **右上「保存する」**

### 注文が入ったら
- 左メニュー「注文」で確認 → 商品を**クール便で発送**（最大10日以内）
- 入金・発送状況を更新

## 4. LINE公式の操作
### ログイン
`https://manager.line.biz` → マル和ミートを選択

### あいさつメッセージ
- 「ホーム」→「あいさつメッセージ」で編集

### リッチメニュー（ボタンのリンク変更）
1. 「トークルーム管理」→「リッチメニュー」→ 編集
2. マスをクリック → アクション設定
   - 通販／ギフト → `https://maruwameat.base.shop`
   - お店に問い合わせ → `https://maruwameat.com/#stores`
   - 卸注文 → アクション「テキスト」＝送信文「卸注文」

### 卸注文の自動応答（キーワード応答）
- 「応答メッセージ」→ キーワード `卸注文`（完全一致）に、注文フォーム案内文を設定
- ⚠️ **応答モードは「Bot」にする**（「チャット」だと自動応答が動かない）：設定→応答設定

### メッセージ配信（お知らせ）
- 「メッセージ配信」から、友だち全員へお知らせを送れる（セール情報など）

## 5. よくあるトラブルと対処
| 症状 | 原因 | 対処 |
|------|------|------|
| サイト更新が反映されない | ブラウザのキャッシュ | URL末尾に `?2`、または Mac:`⌘+Shift+R`／Win:`Ctrl+Shift+R` |
| BASE決済が却下される | 住所が店舗になっている | 本人確認書類（免許証）どおりの**個人の現住所**で再申請 |
| 卸注文が反応しない | 応答モードが「チャット」 | 応答モードを「Bot」に＋キーワード「卸注文」完全一致 |
| 注文者に「受け付けてない」と返信 | デフォルト応答が初期テンプレのまま | 応答メッセージを「受付・連絡します」系に変更 |
| 画像が404 | URLの打ち間違い／未アップ | ファイル名・パスを確認。画像はリポジトリに置く |
