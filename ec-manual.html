3かんたんな選び方

BASE を選ぶ
とにかく無料・最速・簡単に始めたい。まずやってみたい初めての方に。
STORES を選ぶ
デザインのきれいさや、自動で入金される手軽さ、予約連携を重視する方に。
Shopify を選ぶ
月額を払ってでも本格的なブランドEC・拡張性・将来の海外も視野に入れる方に。

迷ったら

まずは無料のBASEかSTORESでスタート → 売上が伸びてきたらShopifyへ移行、が堅実です（売上が大きいほどShopifyが手数料面で有利になります）。

4お申し込み手順（各サービス）

① BASE（ベイス）

  1. 公式サイトで「無料でネットショップを開く」をクリック
  2. メールアドレス・パスワード・ショップのURLを入力
  3. 届いた確認メールのリンクをクリック
  4. ショップ名・カテゴリを設定 → 開設完了
▶ BASE 公式サイトを開く

② STORES（ストアーズ）

  1. 公式サイトで「無料ではじめる」をクリック
  2. メールアドレス・パスワードを入力
  3. 届いた確認メールのリンクをクリック
  4. ショップ名などを設定 → 開設完了
▶ STORES 公式サイトを開く

③ Shopify（ショッピファイ）

  1. 公式サイトで「無料体験をはじめる」をクリック（初回は無料トライアルあり）
  2. メールアドレスを入力してアカウント作成
  3. ストア名・基本情報を設定
  4. プラン（ベーシック等）を選択 → 開設完了
▶ Shopify 公式サイトを開く

6お支払い・入金のきほん

項目内容
月額利用料無料プランなら0円（支払い不要）。有料プランはクレジットカード払い（口座の自動引き落としは基本なし）。
売上金の受け取り「引き落とし」ではなく、登録した銀行口座へ「振込」で入金されます。
お客様の支払い方法クレジットカード／コンビニ／銀行振込／後払い（ペイディ・atone）／PayPay／キャリア決済 など。お客様が銀行振込で払うことも可能。

補足：業務用・卸（BtoB）の受発注

飲食店などへの卸（掛け払い・取引先別価格）は、BASE/STORESよりも卸専用の「Bカート」などが適しています。一般のお客様向け通販とは分けて考えるのがおすすめです。
